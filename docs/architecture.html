Rules of the box

  1. Edge never reasons. It talks to the internet and the bus, and reads Atlas only to render.
  2. Brain never touches the internet. It reads the bus and Atlas. Swap NWS for anything and the brain is unchanged.
  3. Bus is transport, Atlas is truth. Streams are trimmed; a replay is a Mongo query, not an xrange.
  4. Hatchet owns time, FastStream owns fan-in. Durable waits, cron and retries on one side; subscribers on the other. They never overlap.
  5. The agent reads scores; only code writes them. The scorer is deterministic. The agent's sole write is its own rulebook.
